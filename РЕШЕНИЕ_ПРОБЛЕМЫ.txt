ОШИБКА 1: "CORS policy" в консоли
   Причина: Страница открыта через file://
   Решение: Открой http://localhost:8000/

ОШИБКА 2: "ERR_CONNECTION_REFUSED"
   Причина: Сервер не запущен
   Решение: npm start

ОШИБКА 3: "Failed to fetch" или "NetworkError"
   Причина: Сервер недоступен
   Решение: Проверь, что сервер работает:
            netstat -ano | findstr ":8000"

ОШИБКА 4: "База данных временно недоступна"
   Причина: PostgreSQL не запущен
   Решение: docker start wedding-postgres

Открыть фронтенд:
   Start-Process "http://localhost:8000/"

Проверить статус сервера:
   netstat -ano | findstr ":8000"

Остановить сервер:
   Get-Process -Name node | Stop-Process -Force

Запустить сервер:
   cd WeddingV3-main
   npm start

Проверить PostgreSQL:
   docker ps | findstr wedding-postgres

Запустить PostgreSQL:
   docker start wedding-postgres

Автоматический тест:
   cd WeddingV3-main
   node test-auth.js
