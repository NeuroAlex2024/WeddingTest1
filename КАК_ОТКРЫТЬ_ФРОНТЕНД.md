# ⚠️ ВАЖНО: Как правильно открыть фронтенд

## ❌ НЕПРАВИЛЬНО:

**НЕ открывай index.html двойным кликом из папки!**

Если ты откроешь файл напрямую, в адресной строке браузера будет:
```
file:///C:/Users/ALEX_Business/Desktop/test/WeddingV3-main/index.html
```

В этом случае ты получишь ошибку:
```
"Произошла ошибка соединения. Попробуйте позже."
```

**Причина:** Браузер блокирует запросы с `file://` на `http://localhost:8000` из-за политики CORS.

---

## ✅ ПРАВИЛЬНО:

**Открывай страницу через браузер по адресу:**

```
http://localhost:8000/
```

или

```
http://127.0.0.1:8000/
```

---

## 🚀 Пошаговая инструкция:

1. **Убедись, что сервер запущен:**
   ```
   Сервер должен быть запущен в отдельном окне PowerShell
   ```

2. **Открой браузер** (Chrome, Firefox, Edge, и т.д.)

3. **Введи в адресной строке:**
   ```
   http://localhost:8000/
   ```

4. **Нажми Enter**

5. **Проверь, что в адресной строке:**
   ```
   http://localhost:8000/
   ```
   А НЕ `file:///...`

---

## 🧪 Быстрая проверка:

Открой браузер и перейди по этим ссылкам:

### Фронтенд:
http://localhost:8000/

### API тест (регистрация):
http://localhost:8000/api/auth/register
(должна вернуть ошибку "Необходимо указать номер телефона." - это нормально, значит API работает)

---

## 🔍 Если все равно ошибка:

### 1. Открой консоль браузера:

- **Chrome/Edge:** F12 → вкладка "Console"
- **Firefox:** F12 → вкладка "Консоль"

### 2. Обнови страницу (F5)

### 3. Посмотри на ошибки в консоли:

**Если видишь:**
```
Access to fetch at 'http://localhost:8000/api/...' from origin 'file://' 
has been blocked by CORS policy
```

**Решение:** Открывай страницу через http://localhost:8000/, а не file://

---

**Если видишь:**
```
net::ERR_CONNECTION_REFUSED
```

**Решение:** Сервер не запущен. Запусти:
```powershell
cd WeddingV3-main
npm start
```

---

**Если видишь:**
```
Failed to fetch
NetworkError
```

**Решение:** Проверь, что сервер работает:
```powershell
netstat -ano | findstr ":8000"
```

Должен быть вывод:
```
TCP    0.0.0.0:8000           0.0.0.0:0              LISTENING
```

## 🌐 Альтернативные адреса:

Можешь открыть по любому из этих адресов:

- http://localhost:8000/
- http://127.0.0.1:8000/
- http://0.0.0.0:8000/ (может не работать в некоторых браузерах)

Все они ведут на один сервер!
