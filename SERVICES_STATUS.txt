🛑 ОСТАНОВИТЬ СЕРВЕР:

🛑 ОСТАНОВИТЬ POSTGRESQL:

🔄 ПЕРЕЗАПУСТИТЬ POSTGRESQL:
   docker restart wedding-postgres

▶️  ЗАПУСТИТЬ СЕРВЕР СНОВА:
   cd WeddingV3-main
   npm start

🔍 ПРОВЕРИТЬ ЛОГИ POSTGRESQL:
